## Scope and prior art

M4 counts ordinary (possibly chorded), unoriented, unrooted simple C8 using
exactly four coordinate directions. It does not count all ordinary C8.

Füredi–Özkahya, *On 14-cycle-free subgraphs of the hypercube*, author manuscript
https://yunus.hacettepe.edu.tr/~ozkahya/pub/C14_2009.pdf : §2.3 (p.3)
explicitly gives the 648 normalization; §2.5 (p.4), equations (5)–(7), gives
an auxiliary-graph supersaturation argument attributed there to Chung.
Its lifted C4 uses four distinct directions. Thus MSCS(4) is a consequence
of this established mechanism, not a residual novelty claim.

The 2024 layer paper https://pmc.ncbi.nlm.nih.gov/articles/PMC11573844/
Theorem 7 and preceding C8 example are consistent with this embedding.
Ordinary Turán-zero alone is not the logical justification used here.
The k=5 positive-density C10-free exception remains mandatory; nothing here
extends to it or settles Hamiltonian direction profiles or general k.

## Self-contained conservative bound (working proof for independent review)

Let delta=e(F)/(n*2^(n-1)), and d(v) denote the spanning graph degree.
For each x, define H_x on [n]: ij is an edge when both
{x xor 2^i, x xor 2^i xor 2^j} and
{x xor 2^j, x xor 2^i xor 2^j} belong to F.
Here indices i run from 0 to n-1. A wedge centered at y determines uniquely
x=y xor 2^i xor 2^j, so

    sum_x e(H_x) = sum_y binom(d(y),2)
                 >= 2^n (delta^2*n^2-delta*n)/2.

Each ordered injective C4 (i,j,k,l) in H_x lifts to

    x^i, x^i^j, x^j, x^j^k, x^k, x^k^l, x^l, x^l^i.

All eight vertices are distinct: singletons and adjacent pairs are distinct
subsets of four distinct coordinates. All edges are present and the support
is exactly {i,j,k,l}. A fixed lifted cycle lies in a unique four-face;
its possible centers x belong to that face (at most 16), and for fixed x
there are at most eight ordered traversals. Thus total ordered lifts <=128 M4.
This intentionally loose multiplicity bound avoids relying on sharper uniqueness.

For any n-vertex graph H, hom(C4,H)=tr(A^4)>=(2e(H)/n)^4:
the largest eigenvalue is at least average degree and all fourth powers are
nonnegative. At most 6n^3 maps of four vertices are noninjective (union bound
on equal vertex pairs). Applying convexity across x yields, with
p=max(0,delta^2-delta/n),

    M4(F) >= max(0, 2^n/128 * (n^4*p^4 - 6*n^3)).

Since M4(Qn)=648 binom(n,4)2^(n-4) <= (27/16)n^4 2^n,
for every fixed delta>0 this proves

    liminf M4(F)/M4(Qn) >= delta^8/216.

In particular eta(delta)=delta^8/432 works for sufficiently large n.
The constants are conservative, not optimal. This is an elementary support
check of known machinery; independent verification remains a gate before
updating the repository's authoritative theorem registry.

## Reproduction and implementation

    python -m oracles.mscs4 > conformance/receipts/mscs4-constructions.json
    python -m unittest tests.test_mscs4 -v
    python -m oracles.mscs4 path/to/input.json

Input is {"n":4,"edges":[[0,1],[1,3]]}; vertices are bit integers.
The counter validates edges, deduplicates undirected edges, enumerates simple
length-eight paths, and accepts only the minimum starting vertex and one
orientation. It explicitly tests four-direction support. Complexity is
exponential in n; this is a bounded exact oracle, not a large-n algorithm.

Independent tests compare pair-word templates against traversal on 30 seeded
random Q4 subgraphs, verify one-cycle/deleted-edge controls and malformed
edges, and retain Q4=648, Q5=6480 plus the existing restricted-growth oracle.
Auxiliary C4 counts provide another one-sided proof check.

## Construction results

All counts and rational densities for n=4..7 are in the JSON receipt.

| Family | Q4 density / M4 | Q5 density / M4 | Q6 density / M4 | Q7 density / M4 |
|---|---|---|---|---|
| Full | 1 / 648 | 1 / 6480 | 1 / 38880 | 1 / 181440 |
| Even lower-weight edge layers | 1/2 / 3 | 1/2 / 30 | 1/2 / 180 | 1/2 / 840 |
| One middle edge layer | 3/8 / 3 | 3/8 / 30 | 5/16 / 135 | 5/16 / 630 |
| First floor(n/2) directions | 1/2 / 0 | 2/5 / 0 | 1/2 / 0 | 3/7 / 0 |
| Fixed three directions | 3/4 / 0 | 3/5 / 0 | 1/2 / 0 | 3/7 / 0 |
| Lower-weight parity equals direction parity | 1/2 / 3 | 1/2 / 30 | 1/2 / 180 | 1/2 / 840 |

The last parity family means weight(lower endpoint) mod 2 equals the
zero-based flipped-coordinate index mod 2; the name in the receipt is
`parity_other_coordinates`. This is a defined test family, not an attribution
to an extremal construction from the literature.

Finite zero counts do not contradict an eventually-in-n assertion. A fixed
three-direction family has density 3/n ->0. More generally m active directions
have density m/n and exactly 648 binom(m,4)2^(n-4) cycles, hence ratio
binom(m,4)/binom(n,4). With m/n ->alpha>0 this tends to alpha^4>0:
the half-direction family fails as an asymptotic obstruction. One middle
layer has density binom(n-1,floor((n-1)/2))/2^(n-1) ->0. The alternate-layer
family maintains density 1/2 and retains cycles. None of these gives an
asymptotic obstruction, as required by the bound above.
